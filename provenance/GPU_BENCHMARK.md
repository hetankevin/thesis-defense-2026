# Dhaka cholera particle-filter timings

Warm seconds for 36 starting parameter vectors × 36 replicate filters, J = 5,000 particles per filter, T = 600 monthly observations, 20 Euler steps per interval. GPU values use float32 and one NVIDIA RTX 3090. The warm benchmark is the timed second call using fresh seeds after JIT compilation, without error bars. Each adapter resamples at each observation (pfjax multinomial, the other GPU packages systematic). Parallel PyPOMP XLA 7.4924 s and CuTe/Threefry 3.2705 s, pfjax 11.2347 s, cuthbert 11.646 s, pyDPF 67.8678 s. PyPOMP 1.2.0 with serial replicates 10.5832 s. The 2.29× ratio uses XLA with parallel replicates. Matched commit 299fbc8 independently reports 7.5 vs 3.3 s with the same Threefry RNG. The 16.1644 s CuTe first call vs 9.4305 s XLA in the cross-library benchmark excludes separate model construction.
